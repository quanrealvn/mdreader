# Open in MdReader

Adds an **Open in MdReader** command to VS Code, so you can read the Markdown file you're working on in [MdReader](https://github.com/quanrealvn/mdreader).

You'll find it when you right-click a `.md` file in the Explorer (select several to open them all), in the editor title bar, and in the Command Palette.

MdReader shows the saved file and reloads it every time you save, so you can keep it open next to your editor.

## Requirements

Windows, with MdReader installed. [Download it here](https://github.com/quanrealvn/mdreader/releases/latest/download/MdReader-Setup.exe).

## Settings

`mdreader.executablePath` is the full path to `MdReader.exe`. You only need it if MdReader isn't in its default install location.
